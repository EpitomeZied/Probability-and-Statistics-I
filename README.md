# Probability & Statistics I

Lecture notes, instructional examples, question-only practice sheets, and quizzes maintained by **Mahmoud AboZied**.

| Folder | Contents |

## Study route

1. Read the [course guide](notes/course-guide.md) and select a [lecture](lectures/README.md).
2. Work through the explanations and instructional examples.
3. Attempt the corresponding [practice sheets](practice/README.md).
4. Use the [question bank](practice/question-bank.md) and [Quiz 1 models](quizzes/quiz-01/README.md) for review.

The consolidated notes extend through random variables, joint distributions, expected values, limit theorems, and simulation. Section outlines also introduce descriptive statistics, confidence intervals, and hypothesis testing.

## Publication scope

Assignments and quizzes contain questions without answer keys. Instructional explanations, illustrative worked examples, theorem proofs, and code examples are retained. Explicit exercise solutions, homework solutions, and appended answer sections are excluded.

Teacher editions, student records, original files, Typst sources, and local build files are preserved in an ignored `private/` folder. Compiled programs are excluded; PDF teaching handouts are intentionally included. Original author credits remain in the materials.

Quiz models A and B retain the existing questions. Models C-G are parallel variants covering the same skills and marking structure. All navigation links are relative and work in a GitHub checkout.
