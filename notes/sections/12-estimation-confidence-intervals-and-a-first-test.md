# S12 — Estimation, confidence intervals, and a first test

> [!NOTE]
> Probability and Statistics I, section 12. Index: [Probability and Statistics I Sections](../section-plan.md) · questions: [Probability and Statistics I Question Bank](../../practice/question-bank.md) · teaching notes: [Probability and Statistics I Playbook](../teaching-playbook.md).

**One idea to land:** the interval is random, the parameter is not. **"95% confident" is a statement about the procedure**, not about this one interval.

**Board:**
1. Point estimate vs interval estimate; the interval as `estimate ± margin`, with the margin decomposed into (critical value) × (standard error).
2. What changes the width: n, confidence level, σ — one at a time, each with a redrawn picture.
3. The interpretation sentence, written out and pinned, plus the wrong version beside it:
   - ✅ "If we repeated this sampling many times, about 95% of the intervals built this way would contain μ."
   - ❌ "There is a 95% probability that μ is in this interval."
4. Hypothesis testing introduced as the same machinery pointed the other way: H₀, H₁, test statistic, p-value as "probability of data this extreme *if H₀ were true*", decision, **and a conclusion in the problem's own words**.
5. Why we never "prove H₀."

**They solve:** build a CI from given data, interpret it in one sentence; then a one-sample test with the conclusion written in the problem's language, not in symbols.

**Mistakes I expect:** the probability interpretation of a CI; "we accept H₀"; reading the p-value as `P(H₀ is true)`; comparing the p-value to the wrong tail; stopping at "reject" with no sentence about the actual situation.

**Close:** "A number with no sentence is not an answer in this subject. The sentence is the subject."
